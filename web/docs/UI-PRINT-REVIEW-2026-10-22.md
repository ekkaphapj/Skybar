# ผลตรวจ UI และเครื่องพิมพ์ 22 ตุลาคม 2026

- ปรับหน้าจอสีครีม/เขียว/ทอง พร้อมโลโก้เดิม เมนูด้านข้างบน PC และแถบล่างบนมือถือ
- ตรวจ DOM ไม่มีแนวนอนล้นที่หน้าหลัก 390/1440 และประวัติ 320/768 พิกเซล
- เปิดโต๊ะ 1–20 ชื่อไม่จำเป็น บันทึกออร์เดอร์ กลับเข้ามาดู และเช็คบิลเข้าประวัติ
- ตรวจหน้าต่าง RawBT สร้าง URI จาก ESC/POS raster จริงและลิงก์ดาวน์โหลด PNG ได้ โดยไม่เรียกแอปบน PC
- ใบเสร็จ 58 มม. 384 dots รองรับภาษาไทยแบบภาพ และลูกค้า/ร้านค้า 2 ชุดในงานเดียว
- Windows Cottage POS-58 / USB002: ผู้ใช้ยืนยัน ASCII ออกอ่านได้ ภาษาไทยออกครบ และเช็คบิลโต๊ะ 3 ทดสอบออกครบ 2 ชุดอ่านได้
- Print Agent 2.0 ทำงานบนเครื่องนี้ที่ 127.0.0.1:9131 อยู่ร่วมกับ agent รุ่นเก่า 9130 ได้ ต้องเปิด agent ระหว่างใช้งาน
- Android ยังไม่ได้ติดตั้ง RawBT/ทดสอบอุปกรณ์จริง ติดตั้ง จับคู่ Bluetooth เลือกเครื่องใน RawBT แล้วทดสอบก่อนใช้งาน
- ผ่านอัตโนมัติ 190 ข้อ: logic 16, frontend 29, receipt 14, agent 15, API 71, regression 17, orders 28
- Integration tests ทำบน localhost ฐานทดสอบเท่านั้น พร้อมคืนข้อมูลทดสอบก่อนหน้า ไม่เพิ่มยอดขายทดสอบบน production
- Node syntax checks app.js, receipt.js, printing.js, server.js ผ่าน

## เครื่องเพิ่มเติม AiYin AN581 (USB003)
- เพิ่มคิว Cottage AiYin AN581 Thermal ด้วย Generic / Text Only
- ส่งบิลภาพภาษาไทยจากเว็บ production: รับเข้าคิวและคิวหมด แต่ผู้ใช้แจ้งกระดาษเปล่า
- ส่งทดสอบ ASCII + ESC * แถบดำ: ผู้ใช้แจ้งกระดาษเปล่า
- หลังผู้ใช้กลับด้านม้วน ส่งบิลภาพซ้ำ: ยังเปล่า
- ยังไม่ผ่านการยืนยันใช้งาน รอทดสอบม้วนจาก POS-58 ที่พิมพ์ติดและตรวจอะแดปเตอร์ของ AiYin ก่อนวินิจฉัยต่อ
- หลังผู้ใช้เปลี่ยนกระดาษ ส่งบิลทดสอบภาษาไทย 58 มม. ยอด 85.00 บาทจากเว็บ production อีกครั้ง ผู้ใช้ยืนยัน “ออกครบ ภาษาไทยอ่านได้” — AiYin AN581 ผ่านการทดสอบจริงแล้ว
- หน้าเว็บ Chrome เลือกคิว Cottage AiYin AN581 Thermal ไว้สำหรับเครื่องนี้
