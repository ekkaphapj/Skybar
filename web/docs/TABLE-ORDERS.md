# การขายแยกตามโต๊ะ

- กด **เปิดการขาย** เลือกโต๊ะ 1–20 ชื่อลูกค้าไม่บังคับ โต๊ะที่เปิดอยู่เลือกซ้ำไม่ได้
- โต๊ะปรากฏใน **โต๊ะที่กำลังมีการขาย** บนหน้าหลัก กดเพื่อดู/เพิ่ม/ลบรายการ
- การเปลี่ยนสินค้า ชื่อ ผู้ขาย และเลขห้องบันทึกลง D1 ปุ่ม **ปิดหน้ารายการ / กลับหน้าหลัก** จะรอการบันทึกเสร็จก่อนออก กลับเข้าโต๊ะเดิมแล้วเห็นรายการเดิม
- รายการที่ยังไม่เช็คบิลยังไม่ลงยอดขายและยังไม่ตัดสต็อก เมื่อหลายเครื่องแก้โต๊ะเดียวกัน ระบบตรวจ revision และแจ้งให้โหลดข้อมูลใหม่ แทนการทับรายการของอีกเครื่อง
- กด **ปิดการขาย/เช็คบิล** ระบบลงยอดขาย บัญชี เงินสด และตัดสต็อก พร้อมย้ายโต๊ะไปสถานะปิดใน transaction เดียว ป้องกันเช็คบิลซ้ำ
- หลังเช็คบิล ระบบแสดงปุ่ม **พิมพ์ใบเสร็จ** และ **พิมพ์สำเนา** แยกกัน ไม่ส่งงานพิมพ์อัตโนมัติ แต่ละปุ่มส่งครั้งละ 1 ใบตามโหมด USB / RawBT / เบราว์เซอร์ที่ตั้งไว้ ตัดกระดาษก่อนกดพิมพ์ใบถัดไป สำเนามีข้อความสำเนา / COPY
- ใน dialog **เช็คบิลสำเร็จ** กดกลับหน้าหลักได้โดยไม่ต้องพิมพ์ แล้วใช้เบอร์โต๊ะเดิมสำหรับบิลใหม่ได้ ระหว่างเตรียมงานพิมพ์ระบบล็อกปุ่มป้องกันกดซ้ำ
- **ประวัติการขาย** แสดงโต๊ะที่เช็คบิลแล้ว กรองช่วงวันที่ เปิดดูรายการ และเลือกพิมพ์ใบเสร็จหรือสำเนาซ้ำได้ทีละใบ
- ไฟล์สำรองใหม่มี 9 ตาราง รวม TableOrders ไฟล์เก่า 8 ตารางรับเข้าได้เฉพาะเมื่อไม่มีข้อมูลโต๊ะ เพื่อไม่ลบโต๊ะหรือประวัติโดยไม่ตั้งใจ
