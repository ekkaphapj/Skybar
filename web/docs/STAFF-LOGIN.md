# บัญชีผู้ใช้และพนักงาน

เข้าเว็บด้วยชื่อผู้ใช้ admin และรหัสผ่านเริ่มต้น 1234 ตามที่เจ้าของระบบกำหนด
บัญชี admin เป็นผู้ดูแลระบบ ส่วนบัญชีที่เพิ่มใหม่เป็นพนักงาน

## เพิ่มพนักงาน
1. admin เข้าสู่ระบบและเปิดเมนู จัดการพนักงาน
2. ใส่ชื่อที่แสดงในรายการ ชื่อผู้ใช้ และรหัสผ่านอย่างน้อย 4 ตัวอักษร
3. พนักงานใช้บัญชีนี้ล็อกอิน ระบบเลือกชื่อผู้ขาย/ผู้บันทึกให้อัตโนมัติ
4. แอดมินแก้ไขชื่อ รีเซ็ตรหัสผ่าน และปิด/เปิดบัญชีได้ เมื่อบันทึกจะยกเลิกเซสชันของผู้ใช้นั้น
5. แอดมินแก้ไขรหัสผ่านของตนเองได้จากรายการผู้ใช้ แล้วเข้าสู่ระบบใหม่

ชื่อผู้ใช้รองรับ a-z, 0-9, จุด, ขีดกลางและขีดล่าง ไม่แยกตัวพิมพ์ใหญ่เล็ก ชื่อพนักงานรองรับภาษาไทย

## การทำรายการ
- เซิร์ฟเวอร์บันทึกชื่อจากบัญชีปัจจุบัน ไม่เชื่อชื่อผู้ขายที่ส่งมาจากเบราว์เซอร์
- เปิดโต๊ะบันทึกผู้เปิดไว้แยกจากผู้เช็คบิล พนักงานคนอื่นเปิดดูหรือทำรายการโต๊ะเดิมต่อได้
- ผู้เช็คบิลปรากฏในประวัติและใบเสร็จ เพิ่มสินค้า สต็อก บัญชี เงินสด และออก Voucher ใช้ชื่อผู้ทำรายการ
- ชื่อบนประวัติ/ใบเสร็จเก่าคงเป็นชื่อที่บันทึกตอนทำรายการ
- พนักงานทำงานขายและธุรกรรมได้ แต่เข้าจัดการบัญชีหรือสำรอง/นำเข้าฐานข้อมูลไม่ได้

## ข้อมูลและเซสชัน
- รหัสผ่านเก็บเป็น PBKDF2-SHA256 พร้อม salt ต่อผู้ใช้ ไม่มีรหัสผ่านตัวจริงในฐานข้อมูล
- โทเคนเซสชันสุ่ม เก็บเฉพาะ SHA-256 ใน D1 มีอายุ 12 ชั่วโมง Cookie เป็น HttpOnly / SameSite Strict / Secure บน HTTPS
- ล็อกอินผิดเกิน 5 ครั้งต่อชื่อผู้ใช้และ IP ภายใน 15 นาที จะถูกจำกัดชั่วคราว
- ระบบ PIN และ cookie เดิมไม่ใช้ยืนยันตัวตนอีก ต้องเข้าสู่ระบบด้วยบัญชีหลังอัปเดต
- ไฟล์ JSON สำรองจากหน้าเว็บเก็บข้อมูลธุรกิจ 9 ตาราง ไม่รวม Users, UserSessions และ LoginAttempts เพื่อไม่ให้นำเข้าข้อมูลขายไปทับสิทธิ์บัญชี
- การสำรองเต็มระบบรวมบัญชี ใช้ Wrangler D1 export บนผู้ดูแลระบบ
