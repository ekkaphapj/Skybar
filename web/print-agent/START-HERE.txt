COTTAGE POS PRINT AGENT 2.0.2 - WINDOWS x64
=========================================
ชุดพร้อมใช้สำหรับ Windows 10/11 แบบ 64-bit รวม Node.js แล้ว ไม่ต้องติดตั้ง Node.js หรือ npm เพิ่ม

ติดตั้งอีกเครื่อง
1. แตก ZIP ทั้งหมดก่อน เช่น C:\CottagePrintAgent ห้ามเปิด start.bat จากใน ZIP
2. ต่อ USB เปิดเครื่องพิมพ์ และใส่กระดาษ thermal ให้ถูกด้าน
3. ถ้าเป็น POS-58 หรือ AiYin AN581 และยังไม่มีเครื่องพิมพ์ใน Windows:
   เปิด setup-thermal.bat (หากแจ้ง Access denied ให้คลิกขวา Run as administrator)
   ตัวตั้งค่าตรวจเฉพาะเครื่องที่เชื่อมต่ออยู่ ไม่ย้ายพอร์ตของคิวเดิม
   รุ่นอื่นให้ติดตั้งไดรเวอร์ของผู้ผลิตก่อน
4. เปิด start.bat แล้วปล่อยหน้าต่างนี้ไว้ระหว่างขาย
5. เปิด https://cottage-skybar-pos.ekapap-j.workers.dev/ ใน Chrome หรือ Edge
   เข้าสู่ระบบ > ตั้งค่าการพิมพ์ > USB thermal Windows PC
   เลือก Cottage POS-58 หรือ Cottage AiYin AN581 Thermal และกระดาษ 58mm
   ถ้าเบราว์เซอร์ถามสิทธิ์เครือข่ายภายใน ให้กดอนุญาต
6. กดทดสอบพิมพ์ ตรวจภาษาไทย ยอด 85.00 บาท และข้อความทดสอบเท่านั้น

ทุกครั้งที่เปิดคอม ให้เปิด start.bat ก่อนใช้เว็บ POS
ตรวจระบบด้วย check.bat เมื่อไม่พบเครื่องพิมพ์หรือไม่พบ agent

การเช็คบิลส่งใบเสร็จลูกค้าและร้านค้า 2 ชุดในงานเดียว พร้อมป้องกันงานซ้ำ
หากรับเข้าคิวแล้วแต่ไม่ออก ให้ตรวจกระดาษ สาย USB และคิว Windows ก่อนสั่งพิมพ์ซ้ำ

ผลทดสอบรุ่นก่อนหน้า: POS-58 และ AiYin AN581 พิมพ์ภาษาไทย 58 มม. ได้จริง
คอมเครื่องใหม่ต้องกดทดสอบพิมพ์อีกครั้งก่อนเริ่มขาย

รุ่นพร้อมใช้มี runtime\node.exe และ runtime\LICENSE ของ Node.js จาก nodejs.org
ไฟล์แบบ source-only จากหน้าเว็บต้องมี Node.js ในเครื่องก่อน ถ้าไม่ต้องการติดตั้งให้ใช้ ZIP Windows x64 นี้
