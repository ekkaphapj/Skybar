# Cottage POS Print Agent 2.0

โปรแกรมช่วยพิมพ์ USB บน Windows รับภาพใบเสร็จภาษาไทยจากเว็บแล้วส่ง ESC/POS raster เข้าคิว Windows ไม่ต้องเลือก code table ภาษาไทย

## ผลทดสอบคอมเครื่องนี้
Cottage POS-58 ที่ USB002: กระดาษ 58 มม. ภาษาไทย และใบเสร็จลูกค้า/ร้านค้า 2 ชุดในงานเดียว ผู้ใช้ยืนยันว่าพิมพ์ออกครบและอ่านได้

## ติดตั้ง Windows
1. ติดตั้ง Node.js LTS จาก https://nodejs.org หากยังไม่มี
2. แตก ZIP ทั้งหมดไว้โฟลเดอร์เดียวกัน
3. ติดตั้งไดรเวอร์เครื่องพิมพ์ หากเป็น POS-58 ที่ยังไม่มีคิว ให้เปิด setup-pos58.bat โปรแกรมจะตรวจพอร์ต USB และใช้ไดรเวอร์ Generic / Text Only ของ Microsoft หากต้องการสิทธิ์ผู้ดูแล ให้เปิดด้วย Run as administrator
4. เปิด start.bat และปล่อยทำงานระหว่างใช้ POS ใช้พอร์ต 9130 หรือ 9131 หากพอร์ตแรกมีรุ่นเก่าอยู่
5. เปิดเว็บ https://cottage-skybar-pos.ekapap-j.workers.dev/ ด้วย Chrome/Edge เลือกตั้งค่าเครื่องพิมพ์ > USB > Cottage POS-58 > 58 มม. อนุญาตเครือข่ายท้องถิ่นหากเบราว์เซอร์ถาม
6. กดทดสอบพิมพ์ก่อนใช้งานจริง

เช็คบิลจะส่งใบเสร็จ 2 ชุดเป็นงานเดียว พร้อมป้องกันการส่งซ้ำด้วยเลขบิล การรับเข้าคิวไม่ได้ยืนยันว่ากระดาษออก หากสายหลุด/กระดาษหมดให้ตรวจเครื่องและคิว Windows ก่อนพิมพ์ซ้ำจากประวัติ

หากไม่พบ agent ระบบแจ้งข้อผิดพลาด สามารถเลือกโหมดพิมพ์ผ่านเบราว์เซอร์เอง ไม่สลับวิธีพิมพ์อัตโนมัติ

## Android Bluetooth
1. ติดตั้ง RawBT: https://play.google.com/store/apps/details?id=ru.a402d.rawbtprinter
2. จับคู่เครื่องพิมพ์ Bluetooth ใน Android และเลือกเครื่องใน RawBT
3. เปิดเว็บใน Chrome เลือกโหมด Android / RawBT และ 58 มม.
4. กดทดสอบพิมพ์ แล้วแตะปุ่มเปิด RawBT เมื่อเช็คบิลจะเตรียม 2 ชุดในข้อมูลเดียว
5. หากใบเสร็จยาวเกินขีดจำกัดเปิดแอป ให้ดาวน์โหลดรูปแต่ละชุดจากหน้าต่างและเปิดด้วย RawBT

ยังไม่ได้ทดสอบกับโทรศัพท์และเครื่องพิมพ์ Bluetooth จริง ต้องทดสอบก่อนใช้งานบนโทรศัพท์

รูปแบบ rawbt:base64 อ้างอิงตัวอย่างผู้พัฒนา:
https://github.com/402d/DemoRawBtPrinter/blob/master/app/src/main/java/ru/a402d/demorawbt/MainActivity.java

## แก้ปัญหา
- ไม่พบ agent: ตรวจว่า start.bat ทำงานและเว็บได้รับสิทธิ์เครือข่ายท้องถิ่น
- เข้าคิวแต่ไม่ออก: ตรวจ USB กระดาษ และคิว Windows
- งานเดิมอยู่ระหว่างส่งหรือไม่แน่ใจ: ตรวจว่ากระดาษออกแล้วหรือไม่ก่อนพิมพ์ซ้ำ
- รุ่นอื่นพิมพ์เพี้ยน: ต้องรองรับ ESC/POS raster (GS v 0) และเลือกความกว้างถูกต้อง รุ่นที่ยืนยันคือ POS-58 ที่ต่อเครื่องนี้
