# Cottage POS Print Agent 2.0.1

ชุดพร้อมใช้ Windows 10/11 x64: ดาวน์โหลดจาก https://github.com/ekkaphapj/Skybar/releases/latest
ZIP แบบ Windows x64 รวม Node.js และใบอนุญาตแล้ว แตกไฟล์และเปิด start.bat ได้โดยไม่ต้องติดตั้ง Node.js เพิ่ม
อ่าน START-HERE.txt สำหรับขั้นตอนทั้งหมด

## เครื่องพิมพ์
รองรับ ESC/POS raster ภาษาไทยเป็นภาพ ไม่ต้องตั้ง code table ภาษาไทย
รุ่นที่ทดสอบจริงแล้ว: POS-58 และ AiYin AN581 (58 มม.)
เปิด setup-thermal.bat เพื่อตั้งค่าสองรุ่นนี้ หากยังไม่มีคิว Windows ต้องต่อ USB และเปิดเครื่องก่อน
ถ้าต้องใช้สิทธิ์ผู้ดูแล ให้คลิกขวา Run as administrator รุ่นอื่นติดตั้งไดรเวอร์ผู้ผลิตเองก่อน
ไม่แก้คิวที่ชื่อเดิมใช้พอร์ตอื่น และไม่เปลี่ยนเครื่องพิมพ์เริ่มต้นของ Windows

## ใช้งาน
เปิด start.bat แล้วเปิดเว็บ POS ด้วย Chrome/Edge เลือก USB และชื่อเครื่องพิมพ์ กระดาษ 58mm แล้วกดทดสอบพิมพ์
เช็คบิลส่งใบเสร็จลูกค้า/ร้านค้าเป็นงานเดียวและป้องกันการส่งซ้ำตามเลขบิล
Agent ใช้ 127.0.0.1:9130 หรือ 9131 หากมีรุ่นเก่าเปิดอยู่ เฉพาะในเครื่อง ไม่เปิดให้เครื่องอื่นในเครือข่ายเข้าถึง
หากมี agent รุ่นก่อนหน้าอยู่ ให้ปิดหน้าต่างรุ่นเดิมแล้วเปิด start.bat จากโฟลเดอร์ใหม่นี้
ตรวจระบบด้วย check.bat และเปิด agent ทุกครั้งที่ใช้ POS

## Source-only
โฟลเดอร์ source และ ZIP ขนาดเล็กจากหน้าเว็บไม่รวม Node.js สามารถใช้ Node.js LTS ที่ติดตั้งจาก https://nodejs.org ได้
ชุดพร้อมใช้จาก GitHub Releases มีตัวรันใน runtime/ อยู่แล้ว

## Android Bluetooth
Agent นี้สำหรับ Windows USB บน Android ให้ติดตั้ง RawBT จับคู่ Bluetooth และเลือกโหมด Android/RawBT ในเว็บ
https://play.google.com/store/apps/details?id=ru.a402d.rawbtprinter
ยังไม่ได้ทดสอบกับโทรศัพท์และเครื่องพิมพ์ Bluetooth จริง ต้องทดสอบก่อนใช้งาน

## แก้ปัญหา
- กระดาษเปล่า: ตรวจชนิด/ด้านกระดาษ thermal และอะแดปเตอร์ที่มากับเครื่อง
- ไม่พบ agent: ตรวจว่าเปิด start.bat และเบราว์เซอร์อนุญาตเครือข่ายภายใน
- เข้าคิวแต่ไม่ออก: ตรวจ USB กระดาษ และคิว Windows
- งานเดิมอยู่ระหว่างส่งหรือไม่แน่ใจ: ตรวจใบเสร็จก่อนสั่งซ้ำจากประวัติ
- รุ่นอื่นต้องรองรับ ESC/POS raster (GS v 0) จึงจะพิมพ์ได้ด้วยวิธีนี้
